本地模型

下载与运行说明

下载后可离线生成人声，无需 API Key。Kokoro 使用 CPU。首次安装会下载独立 Python、推理依赖与模型，需要联网并预留足够空间。模型来自官方 Hugging Face 仓库或 sherpa-onnx 发布包，通过离线试生成后才显示可用。

单次本地生成最多 300 字，任务依次执行。Qwen 与 CosyVoice 在 CPU 上可能需要数分钟。删除模型会保留共用运行环境与下载缓存。
