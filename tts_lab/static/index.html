在项目根目录将 .env.example 复制为 .env，填写所需服务密钥，保存后重启程序。

凭证仅在本机文件中保存，界面不会显示密钥。检测到配置不代表账号与模型权限已验证。

本地离线模型

下载一次，离线使用

无需 API Key。首次同时下载独立 Python 和推理依赖，请预留空间并保持程序打开。推荐先试 Kokoro + CPU。

模型来自官方 Hugging Face 仓库或 sherpa-onnx 发布包，下载需联网。安装后会离线试生成，通过才显示可用。Qwen 与 CosyVoice 在 CPU 上可能需要数分钟，生成时文本不发送到云端。

使用提示

先确认声音可用

离线测试音只用于检查播放和导出，不朗读文字。下载模型或配置云服务后才能生成真实人声。

让比较更公平

固定文本，一次只改一个参数。开启盲听隐藏服务名称，听完评分后再揭晓。

理解生成耗时

耗时包含完整请求与模型加载，不是首包延迟。云端失败不自动重试，重新调用可能再次收费。
