最近对比

开始前，读这几条

1. 配置一次

在项目根目录把 .env.example 复制为 .env，填写你要测的厂商密钥。重启程序。缺少凭证的服务会显示需要的变量名，页面不接受或保存 API Key。

2. 看清参数

不同引擎只显示各自支持的参数。音色 ID、模型 ID、地区须与你的账号权限匹配。自然语言风格指令不保证逐字生效。

3. 正确解读结果

耗时是完整请求到音频返回的时间，不是首包延迟。并行请求与网络都会影响它。评分是个人主观评价，不是自动客观质量分。

本工具不会自动购买、克隆声音、分享文本或发布音频。所有云端适配器均须你用自己的账号做首次实测；文档核对与模拟测试不能代替真实 API 验证。默认仅监听 127.0.0.1，不要把端口或 .env 暴露到公网。
