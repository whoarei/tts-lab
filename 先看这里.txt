TTS Lab 0.8.0 · Windows 使用说明

0.8.0 新增 DeepSeek 官方独立 TTS，沿用 0.7.0 在线更新和 0.6.0 的 Tauri 2、
系统 WebView2 与随包 Python。
升级沿用原有凭证、方案、历史音频和模型目录。

安装与启动
- 安装版：运行 TTS-Lab-0.8.0-win-x64-setup.exe，按提示安装，从开始菜单打开。
  默认安装到当前用户目录，无需管理员权限。
- 便携版：完整解压 TTS-Lab-0.8.0-win-x64.zip，双击 TTS Lab.exe。请保留旁边的全部文件。
- 支持 Windows 10 / 11 x64，Python 与应用依赖已包含，无需另装 Python 或 Node.js。
- Tauri 版使用 Microsoft Edge WebView2 Runtime。安装版会检测，缺少时联网安装；
  便携版需要先确保系统已安装运行时。离线电脑请提前准备运行时。

在线更新
0.7.0 可在应用内检查并升级至 0.8.0。
0.6.0 没有在线更新功能，需要先手动安装 0.8.0 一次。
桌面版可在“模型配置”的“应用更新”中手动检查，也可从左下角入口打开。
默认启动时检查，每天最多一次；可关闭自动检查，不会自动下载或安装。
发现新版后点击“下载更新”，完成校验后再点“安装并重启”。
请先等待语音生成、方案保存与模型安装完成；安装会关闭应用与本机后端。
任务未结束时已校验的更新包会保留，结束后可再次安装。
安装版运行安装器升级，便携版原地替换应用文件，保留个人数据与其他文件。
网络失败可重试检查或下载，也可从发布页手动安装。
更新使用固定 GitHub Release HTTPS 地址、长度和 SHA256 校验；当前没有独立更新签名，
校验和不代替发布者签名，更新信任本项目 GitHub 仓库与发布账号。
浏览器源码模式不提供原地更新。

三个页面
- 文本测试：选择一个已保存方案，输入文字，生成并试听。
- 方案对比：命名、配置、复制方案，保存后用同一段文字比较，最多 6 组。
- 模型配置：下载本地模型，编辑云服务凭证，打开配置目录。

第一次体验
默认离线测试音可检查播放和导出，但只会产生提示音，不朗读文字。
真实人声可选择以下任一种方式：

本地模型
1. 打开“模型配置”，推荐 Kokoro + CPU，点击“下载并安装”。
2. 安装完成后，在“方案对比”选择本地引擎、模型与音色，命名并保存方案。
3. 在“文本测试”选择方案，输入文字后生成。
首次下载需要联网；之后生成时文字留在本机，无需 API Key，每次最多 300 字。
Qwen3-TTS 和 CosyVoice 需要更多空间与内存，CPU 生成可能较慢。
新增 IndexTTS-2（CPU / NVIDIA GPU）和 GLM-TTS（需要 NVIDIA GPU）。
在“方案对比”导入你有权使用的 3–10 秒 16-bit PCM WAV；GLM 还需准确逐字稿。
录音保存在本机。IndexTTS 已在 Linux CPU 实测生成；GLM 完整 GPU 推理尚未实测。

云服务
1. 打开“模型配置”，点击云服务卡片，在弹窗中填写 Key 等配置。
2. 点击“保存配置”，立即生效，无需重启。Key 默认隐藏，输入时可用小眼睛确认。
   保存后只显示“已配置”，再次打开时留空保留，填写新值替换；取消不保存。
3. 在“方案对比”选择服务和账号支持的模型、音色，命名并保存方案。
4. 在“文本测试”选择方案，输入文字，确认云端调用后生成。
0.8.0 新增 DeepSeek 官方独立 TTS：点击 DeepSeek 卡片配置 API Key，
保存后选择 Stella（默认女声）或 Tide（男声）。
可开关 Markdown 过滤，无需模型名，不提供语速或风格指令；每次最多 2000 字。
输出为 24 kHz 单声道 PCM16 WAV，不上传参考录音。真实账号调用与音质尚未验证。
原有凭证文件不会被升级覆盖；显示已配置不代表账号额度和权限已确认。
同时支持小米 MiMo、字节豆包 / Seed TTS、StepAudio 和 Fish Audio 官方云接口。
在对应服务卡片中填写 Key 并保存即可；Azure、Google 与 AWS 还会显示所需的地域、项目或认证方式。
Fish 还需要声音模型 ID；本次未提供 Fish Speech 本地权重。
云端调用会发送文字和参数，可能收费。显示已配置不等于 Key、余额和权限已验证。
不要分享凭证，不要提交不适合外传的文本。HTTP 错误或超时不会自动重试，请先核对服务状态再决定是否重试。

试听与导出
“方案对比”可开启盲听、揭晓名称、保存真实语音的评分与笔记。
可下载单段音频、本轮音频与配置 ZIP，或导出最近的历史 CSV。
默认测试音不能用于评价语音效果。

数据与升级
在“模型配置”中点击“打开配置目录”即可找到：
凭证：%LOCALAPPDATA%\TTS Lab\credentials.env
方案：%LOCALAPPDATA%\TTS Lab\data\variants.json
历史、音频与评分：%LOCALAPPDATA%\TTS Lab\data
本地模型：%LOCALAPPDATA%\TTS Lab\models
凭证以明文保存在本机，已保存的 Key 不会回显；小眼睛仅显示本次输入。备份时请妥善保管。

升级前先退出应用。安装版可安装新版；便携版解压到新文件夹再打开。
升级、卸载安装版或移除便携程序目录，都会保留个人配置、模型和历史。
如需清理，请自行备份并删除上述用户数据目录。

注意
关闭应用会中断本机等待，云端请求仍可能完成并计费；重新打开后先查看历史。
应用目前未做代码签名，请遵循系统与组织的安全要求。
Windows 原生安装、运行与音频播放的验证情况请查看 VERIFICATION.json。
